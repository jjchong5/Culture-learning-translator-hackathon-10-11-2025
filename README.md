# 🌍 Cultural Translator - Agentic Memory System

Live demo of an AI agent that learns your cultural communication preferences.

## 🧠 Agentic Features
- Multi-step reasoning (visible to user)
- Real-time memory evolution
- Active learning from feedback
- Confidence-aware translations

## 🛠️ Tech Stack
Next.js 14 | Fireworks AI | MongoDB Atlas | TypeScript | Tailwind

## 🚀 Quick Start
1. `npm install`
2. Copy `.env.example` to `.env`
3. Add your MONGODB_URI and FIREWORKS_API_KEY
4. `npm run dev`
